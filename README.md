# C13PowerDashboard

Дашборд електроживлення будинку «Чавдар 13» і звіт про роботу генератора. Статична сторінка (HTML/CSS/JavaScript) читає дані з Cloudflare Worker. **Worker не звертається до Deye**: усі дані йому надсилає C#-застосунок `ScheduleDisconnectLight` (GitHub Actions, ~кожні 2 хв).

```
Deye Cloud → ScheduleDisconnectLight (C#) → Google Sheet + POST /api/ingest → Worker (KV) → сторінка (public/)
```

Формат даних між C# і Worker: [INGEST.md](INGEST.md). Техдеталі: [TECHNICAL.md](TECHNICAL.md), вступ для AI-чату: [AI-CONTEXT.md](AI-CONTEXT.md).

## Worker (`worker/index.mjs`, `wrangler.toml`)

| Ендпоінт | Призначення |
|---|---|
| `POST /api/ingest` | знімок поточного стану + хеші журналу й заправок; відповідь `needJournal` / `needRefuels` |
| `POST /api/ingest/journal` | повний журнал (лише коли хеш відрізняється) |
| `POST /api/ingest/refuels` | повні заправки (лише коли хеш відрізняється) |
| `GET /api/status` | стан для дашборда (зі знімка; `stale` через 30 хв без нових даних) |
| `GET /api/generator-report`, `GET /api/generator` | звіт генератора з журналу й заправок, за паролем (`?from=&to=`, до 31 дня) |

Усі POST потребують заголовок `X-Ingest-Secret`. Дані зберігаються в KV (прив'язка `DATA`, namespace `C13PowerDashboard`). Знімок пишеться одразу при зміні статусу (мережа, генератор, інвертор), а при зміні лише часу вимірювання — не частіше ніж раз на 110 секунд (ліміт безкоштовного KV — 1000 записів/добу).

Секрети: `npx wrangler secret put INGEST_SECRET` (спільний з C#), `npx wrangler secret put REPORT_PASSWORD` (необов'язково).
Локально: `.dev.vars` (див. `.dev.vars.example`), `npx wrangler dev`. Публікація: `npx wrangler deploy`.

## Сторінки

Одна сторінка `public/index.html` із трьома закладками: «Стан» (мережа, генератор, інвертор, батарея), «Паливо та ТО» і «Генератор» (відпрацювання генератора за 1/7/14/30 днів або за вибраний період). Дані «Палива й ТО» та «Журналу» вантажаться лише коли відкрити закладку. Адреса Worker — у `<meta name="dashboard-api">`. Локально Live Server (Go Live); `?api=http://127.0.0.1:8787` бере дані з локального Worker.

## Звіт про генератор

Закладка «Паливо та ТО» показує текст, який формує C# (паливо, відпрацював після останньої заправки, ТО, остання заправка): Worker лише відображає готові секції. Закладка «Генератор» показує сеанси за вибраний період, мітки заправок у дні, коли вони були, і підсумок.

Сеанси рахуються з журналу: рядок «Генератор» з OnOff=1 — запуск, наступний з OnOff=0 — зупинка. Тестові рядки (`test`) ігноруються. Максимальна потужність — з колонки G журналу (при зупинці), для сеансу, що триває, — зі знімка (`genPeak`). Заправки передаються окремим блоком. Точність часу — до ~2 хв (інтервал опитування C#).

## Перевірки
